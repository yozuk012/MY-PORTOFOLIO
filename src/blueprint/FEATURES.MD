# fitur fitur yang akan dikembangkan
fitur-fitur yang akan dikembangkan dalam proyek ini meliputi:
1. **Fitur Translate **: fitur ini memungkinkan portofolio ini hanya akan berbahasa inggris dan indonesia, sehingga pengguna dapat dengan mudah memahami konten yang disajikan.

2. **Fitur Dark Mode **: fitur ini memungkinkan pengguna untuk mengubah tampilan portofolio menjadi mode gelap, sehingga lebih nyaman digunakan pada malam hari atau di lingkungan dengan cahaya rendah.

3. **Fitur Auto Intergation **: fitur dapat mengintergrasikan portofolio dengan platform seperti Github [di khsuskan untuk menampilkan project yang telah dibuat oleh pengguna serta user dapat memilih project yang ingin ditampilkan di portofolio], 

4. **Fitur Pembeda Projects **: fitur ini memungkinkan membedakan tag projects hobby dengan projects yang komersial, sehingga pengguna dapat dengan mudah membedakan antara project yang bersifat pribadi dan project yang bersifat komersial [yang dapat dijual jika ada salah satu user yang tertarik membeli].

5. ** Fitur page maintaice **: fitur ini berfungsi sebagai pemberitahuan kepada user jika portofolio sedang dalam perbaikan, sehingga user dapat mengetahui bahwa portofolio sedang dalam proses maintenance dan tidak dapat diakses sementara waktu.
